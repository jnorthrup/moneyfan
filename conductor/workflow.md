# Project Workflow

## Guiding Principles
- The plan is the source of truth for each track.
- Changes must be testable and auditable.
- Favor small, bounded slices over broad refactors.

## Task Workflow
1. Mark the task in progress in the track plan.
2. Implement the smallest slice that moves the track forward.
3. Add tests when behavior changes.
4. Verify with focused commands.
5. Mark the task complete with evidence paths.
